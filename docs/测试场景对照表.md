## n8n Workflow 节点路径图

### Shopify Support Workflow (v3)

```
Webhook Trigger
    ↓
Parse Input (提取 message, platform, orderId)
    ↓
Shopify AI Agent (LangChain + Claude + Pinecone 工具)
    ↓
Parse Classification (解析 JSON，设置 status)
    ↓
Route by Classification (Switch 节点，3 条输出)
    ├─[auto]─────→ Respond (Auto)
    ├─[draft]────→ Respond (Draft)
    └─[escalate]─→ Slack Alert → Respond (Escalate)
```

### Gorgias Support Workflow (v3)

```
Webhook Trigger
    ↓
Parse Input
    ↓
Gorgias AI Agent (识别 Amazon + TikTok 特有风险)
    ↓
Parse Classification
    ↓
Route by Classification
    ├─[auto]─────→ Respond (Auto)
    ├─[draft]────→ Respond (Draft)
    └─[escalate]─→ Slack Alert → Respond (Escalate)
```

### Judge.me Review Workflow (v3)

```
Webhook Trigger
    ↓
Parse Input (提取 reviewId, rating, body)
    ↓
Review AI Agent (生成回复，注意健康声明限制)
    ↓
Parse Reply & Determine Status (根据评分设置 status)
    ↓
Route by Rating (Switch 节点，2 条输出)
    ├─[rating > 3]──→ Respond (Auto Approved)
    └─[rating ≤ 3]──→ Slack Approval Request → Respond (Needs Approval)
```

## 关键验证点 Checklist

### 功能完整性

- [ ] 所有 6 个 Demo 按钮都能触发正确的分类
- [ ] Auto 场景直接回复，无人工介入
- [ ] Draft 场景显示草稿，可编辑/批准/丢弃
- [ ] Escalate 场景显示红色警告，无草稿
- [ ] Review 高分（4-5⭐）自动批准
- [ ] Review 低分（≤3⭐）需要审核

### n8n 执行验证

- [ ] 每次操作在 n8n Executions 中有记录
- [ ] Switch 节点正确路由到对应输出分支
- [ ] AI Agent 节点成功调用 Pinecone 工具
- [ ] Embeddings 节点无报错
- [ ] Slack Alert 节点被触发（escalate 场景）
- [ ] Slack Approval Request 被触发（低分评论）

### 容错机制

- [ ] Slack 未配置时，workflow 仍能完成（跳过通知节点）
- [ ] AI 输出格式错误时，默认升级为 escalate
- [ ] 网络超时时，前端显示 Error 而不是卡死
- [ ] n8n 不可用时，API 返回错误提示

### 符合产品需求

- [ ] 实现产品分析文档中的三层分类逻辑
- [ ] 识别健康副作用投诉并升级
- [ ] 识别平台特有风险（A-to-Z, 差评威胁）
- [ ] 评论回复避免健康功效声明
- [ ] 低分评论不公开承诺退款/优惠
