## 常见问题排查

### Q1: Demo 按钮点击后没有 AI 回复，只显示 Error

**原因：** n8n 未启动或 OpenRouter API Key 无效

**解决：**

1. 确认 n8n 在运行：访问 http://localhost:5678 能打开
2. 检查 `.env.local` 中 `OPENROUTER_API_KEY` 是否正确
3. 查看浏览器 DevTools → Network，确认 `/api/support` 请求的响应

---

### Q2: Review Generate Reply 按钮一直转圈

**原因：** OpenRouter 响应慢或 API 配额不足

**解决：**

1. 访问 https://openrouter.ai/credits 确认余额
2. 查看 n8n Executions 是否有执行记录（无记录说明 webhook 未到达 n8n）

---

### Q3: n8n Executions 里节点显示红色报错

**原因：** Pinecone 或 OpenAI 凭证未配置

**解决：**

1. 在 n8n → Credentials 里确认以下凭证存在且可用：
   - `OpenRouter (OpenAI-compatible)`
   - `OpenAI API`（用于 Embeddings）
   - `Pinecone API`
2. 每个凭证点击 **Test** 验证连通性

---

### Q4: Escalate 场景没有收到 Slack 通知

**原因：** Slack API 凭证未配置或频道配置错误

**解决：**

1. 确认 n8n → Credentials 中有名为 `Slack API` 的凭证
2. 检查 Slack Alert 节点的 `content` 参数中的频道配置
3. 如不需要 Slack 通知，workflow 会自动跳过（`continueOnFail: true`），不影响其他功能

**注意：** Slack 通知为可选功能，未配置时：
- Escalate 场景仍会正确分类并响应前端
- Slack Alert 节点会被跳过
- Workflow 执行状态仍为 Success

---

### Q5: Switch 节点没有正确路由

**原因：** AI 返回的 JSON 格式不符合预期

**解决：**

1. 在 n8n Executions 中查看 `Parse Classification` 节点的输出
2. 确认 `classification` 字段值为 `"auto"` / `"draft"` / `"escalate"` 之一
3. 如 AI 输出格式错误，Parse Classification 会默认设置为 `"escalate"` 以确保安全

## 架构亮点

### 符合产品分析文档要求

本实现完全符合 `/需求/产品分析.md` 中的系统逻辑设计：

```
用户发消息（任一平台）
      ↓
AI 分类：标准问题？
      ├── YES（占约 70-80%）→ 自动回复 ✅
      │     - 物流查询（查订单数据）
      │     - 退换货政策
      │     - 产品 FAQ / 用法说明
      └── NO → 判断风险等级
                  ├── 低风险 → AI 起草 + 人工审核后发送 ✅
                  └── 高风险 → 立即人工接管 + 即时通知 ✅
                        - 副作用/健康投诉
                        - 平台账号威胁
                        - 大客户/KOL
```

### 技术实现特点

1. **条件分支** — Switch 节点根据 AI 分类结果路由到三条不同执行路径
2. **通知机制** — Escalate 场景自动发送 Slack 警报（可选配置）
3. **容错设计** — Slack 节点设置 `continueOnFail: true`，未配置时不影响主流程
4. **智能降级** — AI 输出解析失败时默认升级为 escalate，确保安全
5. **评论分级** — 低分评论（≤3星）自动触发人工审批流程

### 演示价值

- **自动化率可量化**：70-80% 的消息走 auto 路径，直接节省人力
- **风险可控**：高风险场景 100% 人工接管，零误判容忍
- **流程透明**：n8n 可视化流程图，客户可直观理解逻辑
- **平台无关**：Shopify/Amazon/TikTok 使用统一的 AI 分类引擎
- **可扩展**：添加新平台只需复制 workflow 并调整 webhook 路径
